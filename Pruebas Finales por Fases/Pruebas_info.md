Esta carpeta unicamente tendra las pruebas finales de cada fase estudiada.
La prueba consiste en actualizar el codigo mas completo de java con las ultimas herramientas estudiadas.
El proyecto, Epicentro-Gourmet, es el mas complejo y el indicado para poder demostrar la correcta aplicacion de lo estudiado.
Cada fase tendra su propia carpeta con su propio Epicentro-Gourmet.
La metodologia es en cascadas, es decir, Fase 0 tendra el proyecto original sin cambios. Fase 1 tendra el proyecto de Fase 0 + herramientas estudiadas aplicadas en este. Fase 2 tendra el proyecto de Fase 1 y la implementaciones nuevas de esta Fase. Asi sucesivamente hasta terminar la guia de estudio con cada Fase escrita.

Habra un MD en cada Fase explicando lo cambios realizados por arriba. (Que se estudio en esta fase).
